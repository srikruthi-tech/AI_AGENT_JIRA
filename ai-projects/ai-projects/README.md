# AI Projects

A collection of small projects built while learning LLM agents and retrieval-augmented generation (RAG), all running against local models through [Ollama](https://ollama.com).

| Folder | What it is | Stack |
|---|---|---|
| [`jira-ai-agent`](./jira-ai-agent) | Chat interface that manages Jira tickets in plain English using an LLM agent with tools | Python, FastAPI, LangGraph, Ollama, React |
| [`rag-chunking-embeddings`](./rag-chunking-embeddings) | Scripts that split text files into chunks and generate embeddings, saved to CSV | Python, Ollama, Hugging Face, OpenAI |
| [`prompt-response`](./prompt-response) | Finds the most relevant chunks for a prompt using cosine similarity and asks a local LLM for a structured answer | Java, Maven, Ollama |

Each folder has its own README with setup and run instructions.
